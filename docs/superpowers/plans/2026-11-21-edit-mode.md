# Tryb „Edytuj” Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Write on pages, hide data and crop pages in DuckFix, every item editable and undoable, saved into PDF and JPG.

**Architecture:** Items are data on the page (`Page.marks`, `Page.crop`), in the same frame as signatures (fractions of the saved page, top-left). One pure canvas painter draws signatures + marks for export; the browser rasterizer paints them and cuts the crop. The preview draws marks as SVG over the page; an edit mode with a tool strip creates and edits them.

**Tech Stack:** React 18, TS, Vitest (jsdom), pdf-lib, existing rasterizer.

**Spec:** `docs/superpowers/specs/2026-11-21-edit-mode-design.md`

## Global Constraints

- Never push to BuilderHutLabs/duckfix (main); deploy only to BuilderHutLabs/duckfix-v2 (`git push https://github.com/BuilderHutLabs/duckfix-v2.git v2:main`, gh account BuilderHutLabs, switch back to BuilderHut after).
- All UI text in `src/i18n/{pl,en,de,es}.ts` (shape of pl).
- Coordinates: fractions of the saved page before crop, origin top-left (same as `Stamp`).
- A page with any mark or crop is rasterized on export (black cover must remove content).
- Every user change is one undo step (`commit` in store).
- Each stage ends deployed to duckfix-v2 with the full suite green.

## Review Focus

- Black cover on a PDF page with a text layer: saved PDF has no text under it, and "Tekst" does not copy it (pageText must OCR, not read the layer).
- Crop + signature + marks: positions in the saved file match the preview (crop maps all fractions).
- Crop together with rotation 90°/270° and skew: crop is in saved-page frame, so it must be applied after rotation in the rasterizer.
- Edit mode open while the user swipes to the next page / closes preview: no stray selection or half-made item is committed.
- Text with Polish letters (ąęłóśźżćń) renders in canvas export (system sans-serif font, no embedding).

**Interfaces — Produces:**
```ts
export type InkColor = 'black' | 'blue' | 'red';
export interface Box { x: number; y: number; w: number; h: number }
export type Mark =
  | ({ id: string; kind: 'cover'; color: 'white' | 'black' } & Box)
  | ({ id: string; kind: 'text'; text: string; color: InkColor; size: 1 | 2 | 3 } & Box)
  | ({ id: string; kind: 'check' | 'cross'; color: InkColor } & Box)
  | ({ id: string; kind: 'rect' | 'ellipse' | 'arrow'; color: InkColor } & Box) // arrow: from (x,y) to (x+w,y+h), w/h may be negative
  | { id: string; kind: 'pen' | 'highlight'; color: InkColor; points: number[] }; // flat [x0,y0,x1,y1,…]
// Page: marks?: Mark[]; crop?: Box
addMark(doc, pageId, mark): Doc
updateMark(doc, pageId, markId, patch: Partial<Mark>): Doc
removeMark(doc, pageId, markId): Doc
setCrop(doc, pageIds: string[], crop: Box | undefined): Doc   // full page (≈{0,0,1,1}) stored as undefined
```

## Stage 2 — tekst, ✓/✗, data

### Task 5: Text, check, cross, date

**Files:** Modify `src/edit/paint.ts`, `EditLayer`, `EditTools`; Create `src/ui/edit/MarkTextSheet.tsx` (input, colour, size); Test `tests/edit/paint.test.ts`, `tests/ui/edit.test.tsx`

- Tools: Tekst (tap on page → sheet asks for text → mark at tap, width fits text), ✓, ✗ (tap places a square mark), Data (tap places text with today's date in the app language format, `toLocaleDateString(lang)`).
- Colour row (czarny/niebieski/czerwony) and size (S/M/L) shared by tools, remembered in localStorage (`storageKey('duckfix-edit-style')`).
- Text size: `size` maps to font height = 1.6% / 2.4% / 3.6% of page height; box h = font height × lines × 1.25; resizing a text mark scales the font (box h drives font size).
- Painter: text with `ctx.font = \`${px}px sans-serif\``, multi-line split on `\n`; check/cross as strokes, line width = 12% of box.
- Tap on a selected text mark reopens the sheet to edit.

- [ ] Tests: painter calls `fillText` with Polish text and font px from box; ✓ tool tap adds a check at the tap point; Data adds today's date; editing a text mark updates it (one undo step).
- [ ] RED → GREEN → full suite. Commit, browser check, deploy.
